Research Principles

How we keep findings credible while the system is still evolving

Evidence Tiers

Synthetic and observed signals are separated. Observed reality is treated as higher-trust decision evidence.

Explicit Uncertainty

The interface distinguishes screening signals from grounded outcomes and avoids deterministic ranking claims.

Reproducible Flow

Step-based workflows (battery -> variants -> runs -> validation -> iteration) keep experiments comparable across cycles.

Auditability

Validation jobs, observed checks, and loop maintenance are persisted so teams can review why conclusions were made.

Hard Category Gating

Hybrid scoring with category enforcement reduces false positives and improves consistency of bottom-up query generation.

Validation-First

Insights are gated by observed validation thresholds to reduce overfitting to synthetic judges.

Provider Integrations

Synthetic validation supports in-app BYOK and provider-run contracts (OpenAI MCP implemented, Gemini flow scaffolded).

Bottom-Up + Top-Down

Cold-start generation combines product-first and goal-first strategies when loop evidence is sparse.
